# Tata Kelola REKATI

Aturan dan catatan rapat REKATI (Ruang Eksplorasi Kawan Teknologi Informasi), komunitas tech worker di Jakarta Raya dan chapter Tech Workers Coalition (TWC).

Repo ini private: hanya Kawan di organisasi GitHub `rekati-org` yang bisa membaca diskusi, PR, dan notulen. Aturan yang berlaku diterbitkan untuk publik di **[rekati.org/aturan](https://rekati.org/aturan/)**. Setiap kali `ATURAN.md` berubah di `main`, workflow [`terbitkan`](.github/workflows/terbitkan.yml) menyalinnya ke repo situs (`site/src/rules/ATURAN.md` di `rekati-org/rekati`), dan situs ikut diperbarui. Jangan mengubah salinan di repo situs; ubah di sini.

| Berkas | Isi |
| --- | --- |
| [`ATURAN.md`](ATURAN.md) | Aturan Komunitas: siapa Kawan, cara bergabung dan dikeluarkan, pengurus, ruang bersama, kegiatan, sanksi, iuran, keterlibatan di luar Kawan, dan bahan bahasan berikutnya |
| [`notulen/`](notulen) | Notulen rapat, satu berkas per rapat, dinamai `YYYY-MM-DD.md`. Tidak diterbitkan. |

Cara Kawan saling memperlakukan diatur di [Kode Etik](https://rekati.org/kode-etik), bukan di sini.

## Mengubah isi

1. Buat branch dari `main`.
2. Ubah berkasnya, lalu buka PR. Tulis alasannya. Kalau perubahan itu diputuskan di rapat, tautkan notulennya.
3. Minimal satu Kawan lain harus menyetujui PR sebelum di-merge. Jangan push langsung ke `main`: di paket GitHub gratis, repo private tidak bisa dikunci dengan aturan branch, jadi aturan ini dijaga bersama. Riwayat commit tetap mencatat siapa mengubah apa.

Hal yang belum diputuskan ditulis di bagian "Bahan bahasan berikutnya" di akhir `ATURAN.md`, dan dibawa ke rapat berikutnya.

## Privasi

`ATURAN.md` terbit untuk publik. Jangan menulis nama lengkap, nomor telepon, tempat kerja, atau detail lain yang bisa mengungkap identitas Kawan di berkas itu. Di notulen, walaupun tidak diterbitkan, cukup tulis jumlah yang hadir atau peran (misalnya "pengurus verifikasi").
